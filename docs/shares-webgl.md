## v2.1(2026-10-14):操作簡化、點擊修正、相關卡

使用者的原則:**本質是讀卡片,體驗越單純越好**。下面跟 v2 衝突的以這段為準。

- **點擊層鋪滿畫面**:`.sh3d-stage` 改成 `position: fixed`(nav 以下整個畫面)。以前它只有內容欄寬,寬螢幕兩側的卡點不到也停不到,
  這就是「點擊範圍跟卡片不一致」的原因。點擊判定略過淡到 0.85 以上的東西(看不見的卡不擋點擊),卡片上緣的標籤算卡片範圍。
- **桌面俯角 55°**:櫃子是封存,不佔主視覺,只在畫面上緣露一截。換層用 `↑` `↓`、滾輪(往上滾看櫃子、往下滾回桌面;觸控板慣性要停手 0.22 秒才換下一層)、
  手機上下滑(手指往下拉看櫃子、往上滑回桌面)。舞台 `touch-action: none`。
- **桌面只有一層:全景**。6 張平放全部看得到,點(滑鼠或觸控)一下就拿起;沒有「立起來的主角」這個中間狀態(讀者只需要「看全部」與「讀一張」)。
  鍵盤 `←` `→` 讓選中那張浮起並顯示標題,`Enter` 拿起。櫃子層點空白處回桌面(點到櫃框不算),抽屜層點外面關上。
- **點一下就拿起**:滑鼠點抽屜裡、相關卡疊裡任何一張都直接拿起,點旁邊退一層;觸控在抽屜與卡疊保留兩段(第一下撥到,第二下拿起),看的是按下時的 `pointerType`。卡片不亮琥珀。
- **鏡頭避開 nav 與底部工具列**:桌面鏡頭只用 nav 下緣到工具列上緣之間(每格量一次)。直立螢幕兩欄間距 146;相關卡的主角佔寬 56%。
- **抽屜裡用滾輪撥卡**;滑鼠停到哪張就馬上撥到那張(路過也會翻,使用者選擇反應快優先;點也行)。滾輪撥過之後滑鼠要移動 12px 以上,停留選卡才重新生效,兩者不打架。
- **相關卡(trail)**:點卡片上的標籤(桌上或拿起的 HTML 卡)= 直接拿起這張讀,同 tag 的卡從櫃子飛來全部疊在它後面(點的那張排第 1,其餘照時間循環接在後面,
  主角固定在桌面前排正中央;桌上其他卡淡掉)。拿著時 `←` `→` / 滾輪就在這個 tag 裡換。放回去(`Esc`、點外面、放回去鍵)就整疊收回、回到桌面全景,
  **沒有中間的「看那一疊」狀態**。
- **拿著卡時滾輪就是換卡**(桌面、抽屜、相關卡、搜尋牌疊都一樣)。
- **拿起要快**:飛行用較快的趨近、接近到看不出差別就換手(約 0.33 秒,原本約 1 秒),換手淡入 0.12 秒;場景已載入的圖在 HTML 卡上直接顯示不淡入
  (以前會先露出紙色底再淡入,看起來像變色)。拿著一張時點別張直接換成那張,點空白或同一張才放回。
- ~~**提示列一句話**~~(v2.2 拿掉提示句):鍵盤操作收進工具列的 `?` 鍵(按 `?` 或點鍵開關,觸控裝置不顯示)。

## 為什麼要改

1. **跟書架的落差**:書架是走進一個房間,首頁還是桌上一排磁磚。三頁(分享、書架、關於)要是同一個空間。
2. **數量變多**:現在 11 則,幾百則時格狀牆不好逛,也看不出全貌(部落格典藏常見的問題:只有 tag 雲與月份連結,
   看不出哪些舊文值得讀)。
3. **驚喜**:要有一個讓人記得的招牌互動,但不靠炫技特效(評估過 canvas-ui:多數是疊在 HTML 上的特效、風格太搶,
   而且會多一個 WebGL context,不採用)。

## 隱喻

書架那頁是「書在書櫃上」,這頁是「轉發是索引卡」:**最近的攤在桌上,往後一週疊成一疊,全部歸檔在目錄櫃**。
圖書館裡書櫃與卡片目錄本來就放在一起。卡片在桌上 = 還沒整理,歸進抽屜 = 整理過。

- 時間軸(最近看了什麼):桌面與週疊。
- 分類(某個主題有哪些):目錄櫃。
- 同一則轉發同時出現在兩處。

## 動線

頁面照常往下捲(原生捲軸),鏡頭沿著桌子往後走,三段:

1. **桌上**:最近 7 天的卡片平放在桌上,微微歪斜。至少 4 張、最多 12 張(7 天內不到 4 張就補最新的,超過 12 張的進它那一週的疊)。
   最新那張是精選:側面是琥珀色(取代現在的精選卡,琥珀三個時刻的規則照舊)。
2. **週疊**:再往前最近 12 個有轉發的週,一週一疊,越舊越遠,疊的高度 = 那週的張數,疊前面的桌上印著「9/28 那週 · 6」。
   點一疊就攤開在桌上(其他攤開的收回),捲動或 Esc 收回。更早的只在目錄櫃。
3. **目錄櫃**:一格抽屜一組,抽屜面板的標籤框寫組名與張數。分組可換:tag(預設)/ 來源 / 年份。
   換分組時抽屜一格格推出來(錯開約 45ms)。

鏡頭不轉、不翻。攤開週疊、拉開抽屜時鏡頭移過去對準;捲動超過約 140px 就收回並回到捲動路線。

### 目錄櫃的規則

- **多個 tag**:每個 tag 的抽屜各放一張(同一則會出現在多格)。拿起時背面寫「也收在 X、Y 抽屜」。
- **來源分組**:張數最多的 7 個來源各一格(只有 1 張的不算),其餘併成「其他來源」抽屜。
- **年份分組**:新到舊。(原本依月份;格數會一直長,細找交給搜尋。)
- **抽屜容量**:不拆格。張數超過 60 的抽屜只放 60 張(翻過去的留 8 張在前面),翻到哪裡窗口就跟著往後滑一張,看起來是一直翻得下去(`drawerWindow()`)。
- 櫃子 4 欄(超過 16 格時 5 欄),列數依格數;櫃子尺寸變了,鏡頭的停點跟著算(整個櫃子剛好放進畫面)。
- 直立畫面(寬 < 高):桌面、週疊、櫃子都改 2 欄,桌面與週疊往後加深(`arrange()`);鏡頭拉到整排放得進畫面寬度,櫃子太高時捲動最後一段(p 0.8→1)從最上排往下帶。

## 卡片

### 場景裡(遠看、逛):純文字索引卡

og:image 不進 WebGL:實測現在 11 張裡大多沒有 `access-control-allow-origin`,不能當貼圖;
存縮圖進 repo 則犧牲美感(風格雜亂)與空間。所以場景裡是統一的文字卡,辨識度靠:

- **版面**:紙色底、藍色格線、標頭下一條紅線(真的索引卡)。上方來源(等寬)與日期;左側標題(宋體,最多 5 行);底下 tag。
- **來源印章**:右半邊一枚圓形印章,網域主名稱的首字 + 主名稱。墨色色相由網域雜湊決定(顏色來自資料,同書脊的例外)。
- **tag 色標**:卡片上緣凸出一片標籤,顏色與左右位置由主 tag 決定。抽屜裡卡片直立時,一排交錯的色標就是真的目錄卡分隔標籤。
- **心得便利貼**:有 `note` 的卡,右下角貼一張便利貼(`--sticky`)。
- **已開過**(seen 模組):角落一個鉛筆勾。
- **失效改連封存**(archive 模組):斜蓋一個紅色「封存」章。
- 標題可能是中文(issue 覆蓋的標題):換行規則要處理 CJK(逐字斷)。

### 拿起來(近看、讀):換成 HTML 卡

1. 點一張,3D 卡飛到鏡頭前,剛好落在 HTML 卡的位置(鏡頭前固定距離,依 HTML 卡的螢幕矩形算出位置與縮放;
   平行於畫面的平面投影不變形,所以能完全對齊),淡入 0.18 秒換成 HTML 卡,3D 卡隱藏。
2. **正面**:跟 3D 卡同一版面(字級用 container query 單位,比例與貼圖一致),再把 og:image(hotlink,跟現在一樣)
   像剪報一樣貼上去(膠帶、微微歪斜、落下的彈性動畫),蓋在印章的位置。沒有圖或載入失敗就留著印章。
3. **背面**:點卡片或「翻面」(CSS 3D 翻轉,同書架翻封底):心得(沒有就是摘要)、tag、「也收在…」。
4. **換一張**:`←` `→`、左右滑、卡片兩側的 `‹` `›`。範圍跟著從哪裡拿起:桌上 = 桌上那幾張;攤開的週疊 = 那一週;
   抽屜 = 那格抽屜(抽屜同步撥到那張)。到頭時輕彈一下。滑出 150ms、滑入 200ms,剪報重新貼上。
5. **開原文 ↗**:真的 `<a target="_blank" rel="noopener">`,失效且有 `archive` 時連封存版。
6. **放回去**:按鈕、Esc、點外面、捲動。HTML 卡淡出,3D 卡飛回原位。
7. HTML 卡是 `role="dialog"`,文字可選取、螢幕閱讀器讀得到。share 的標題與心得不翻譯。

## 抽屜:撥卡

- 拉開抽屜時鏡頭從前上方俯看進去(約 50 度),看得到後面卡片交錯的色標。
- 卡片全部微微後靠;**目前那張前面的卡全部往前倒**(以底邊為軸,同角度、互相平行,所以不會互穿),那張露出完整正面。
  倒下的卡躺得低,不會擋視線,也不會擋游標。前面留空間給倒下的卡(不穿過抽屜前板)。
- 游標往上掃到後面的卡 = 撥到那張;往下碰到倒下的卡 = 它們站回來。滑鼠點目前那張 = 拿起;點別張 = 撥到那張。
- 鍵盤:`↑` `↓`(或 `←` `→`、`j` `k`)撥卡、`Enter` 拿起、`Esc` 關上抽屜。觸控:點一張撥到那張,再點一次拿起。
- 放回去時抽屜停在最後看的那張。
- 卡片很密的抽屜(幾十張)若用滑鼠抓不準,改成「游標在抽屜裡的上下位置對應第幾張」,不靠 raycast 打中卡片(實作時試手感決定)。

## 燈光:主角最亮,其他退下

| 狀態 | 夜間(檯燈) | 日夜共通(淡出) |
|---|---|---|
| 桌上、週疊 | 檯燈跟著游標(落點在桌面,最遠到櫃子前方,不會跑到櫃子後面) | 櫃子淡 0.15 |
| 捲到櫃子 | 檯燈不跟游標,移到櫃子前上方、調亮,整面抽屜均勻亮起 | 桌上與週疊淡 0.6 |
| 拉開抽屜 | 燈移到那格前上方照進去 | 其他抽屜淡 0.5 |
| 拿著卡片 | 燈移到鏡頭前 | 全部淡 0.35 |

- **淡出 = 往桌面色混**(書架 shader 已有的 `uDim` / `uDesk`):白天變淺,夜間變暗,同一個機制。
- 白天主光從前上方較高處來,抽屜裡的卡不被自己的影子蓋住。
- **停留**:抽屜往外動一點(像被拉一下),標籤框與把手亮琥珀;桌上的卡微微抬起。

## 開場

共用書架的開場(`docs/books-webgl.md`〈載入〉),三頁一致:

- 有 JS 時一開始蓋幕;夜間暗房只看得到桌子、卡片、櫃子的形體(`uUnlit`),白天墨線素描(`uSketch`)。
- 卡片貼圖是本機畫的(不等網路),等字型(`document.fonts.load`:Source Serif 4、JetBrains Mono、Inter、Noto 系列)
  與桌上卡片的貼圖畫好就開燈(至少 300ms、最多 1.5 秒):夜間檯燈閃兩下亮在桌上,白天顏色從中央暈開。
- 開燈前停留、拿起、撥卡、攤開都不反應,提示列不出現。

## 操作提示列

固定在畫面底部(同書架工具列的位置),內容跟著狀態換;抽屜與拿卡時左邊用琥珀色顯示「第幾張 / 共幾張」:

- 桌上:點卡片拿起來 · 捲動看更早的轉發
- 週疊攤開:點卡片拿起來 · Esc 收回這一疊
- 櫃子:點抽屜拉開 · 換分組(tag / 來源 / 年份)
- 抽屜:↑↓ 撥卡 · Enter 拿起來 · Esc 關上抽屜
- 拿著卡:← → 換一張 · 點卡片翻面 · Esc 放回去

觸控裝置(`pointer: coarse`)換成觸控說法(左右滑、點、再點、點外面)。分組切換鈕在櫃子這段出現(`.key`)。
游標停在卡上時,提示列上方浮出標題、來源與日期(抽屜裡加抽屜名)。

## 搜尋(取代 shelf-filter)

- `/` 或提示列的搜尋鈕打開一條 `.groove` 輸入框;比對標題、來源、心得、摘要(同現在 `data-text`)。
- 不符合的卡淡出(同上面的淡出機制),週疊只算符合的張數,抽屜標籤顯示「3 / 12」,0 張的抽屜淡出;撥卡與換一張只在符合的卡之間跳。
- tag 篩選由「依 tag 分組 + 拉開那格」取代。網址 `#tag-<名稱>`(名稱 `encodeURIComponent`,如 `AI%2FLLM`)開啟時捲到櫃子並拉開那格(取代現在的 hash 還原)。
- 沒有 JS 的保底清單照舊沒有篩選。

## 保底與無障礙

- **現在的首頁格狀卡片就是保底**:`share-card.html` 照舊輸出整份清單。沒有 JS、WebGL 開不起來、模組抓不到或執行丟錯(`.fail`)時顯示;
  搜尋引擎、Ctrl+F、RSS 都不受影響。
- WebGL 啟動後清單改成視覺隱藏、留給螢幕閱讀器與鍵盤:Tab 到一張 = 場景裡那張高亮(必要時鏡頭移過去),Enter 拿起。canvas `aria-hidden`。
- 有 JS 時從首次繪製就藏起清單、蓋幕;**不用計時器猜失敗**(同書架 `ed8cd75`)。
- `prefers-reduced-motion`:不飛、不倒、不貼,直接到位;淡入淡出保留。
- 模組:`seen`、`archive` 變成 JSON 裡的旗標與卡片上的記號;模組關掉就不輸出旗標。footer 的「清除已開過」照舊。

## 技術

### 共用場景底座(About 之後也用)

抽出 `assets/scene3d/`,書架與分享頁都從這裡 import:

- `colors.js`(`readTokens(names)`)、`anim.js`(從 `assets/books3d/` 搬過來)。
- `intro.js`:開場亮度曲線(夜間閃燈、白天暈開、快取短版)的純函式與開燈時間常數。
- `glsl.js`:shader 片段 `LIGHT`(`lit()` 打光與檯燈)、`REVEAL` / `SKETCH`(素描);`geometry.js`:`box()`。
- `scene3d.css`:開場幕(`.s3d::before`)與 `.soft` 淡入。
- **留在書架、分享頁照同樣寫法自己實作**(PR 1 決定;兩邊真的長得一樣再合併):開場的狀態機(蓋幕 → 第一格 → 開燈)、
  檯燈落點、`uDim` / `uUnlit` / `uDrop` 的 uniform 與最後一行混色、`invalidate()`、context 遺失後的恢復、`compileAsync` 預熱。
  它們跟書架的單位(px / ppu)和狀態綁在一起。

**搬的時候書架的行為不能變**(同一個 PR 只搬不改,手動比對夜間開場、白天開場、檯燈、拿起)。

### 分享頁

- 程式放 `assets/shares3d/`(`layout.js` 純函式:桌上 / 週疊 / 抽屜分組與位置;`scene.js`;`textures.js`;`main.js`)。
  不放 `assets/modules/`。版面 `_layouts/shares.html`,import map 與 modulepreload 同書架。
- 資料由 Jekyll 輸出成 `<script type="application/json">`:issue、title、href(已套用 archive)、link、source、date、tags、note、
  description、image、dead。不改 `share.py`,**不存縮圖**。
- **卡片本體一次繪製**:InstancedMesh(卡、色標、便利貼各一個),每張的位置、傾斜、淡出、貼圖格號是 instance 屬性。
  不用 three.js 的 shadow map(貴),卡片下方用 `uDrop` 假陰影,同書架。
- **卡片貼圖是池子,不是每張一張**:一張 4096 寬的拼貼貼圖切成 512×307 的格子(約 100 格),只畫看得到的卡
  (桌上 ≤12、攤開的一疊、拉開的抽屜 ≤60、週疊最上面那張),LRU 回收。疊在下面的卡與關著的抽屜不需要正面貼圖。
  縮圖鏈(mipmap)節流,同書架的規則。拿起的卡由 HTML 呈現,不需要高解析貼圖。
- 抽屜面板的標籤也畫進拼貼貼圖。換分組時重畫。
- 點擊判定:raycast 打卡片與抽屜;櫃身與桌面算遮擋。
- 介面文字(提示列、分組名、張數、「也收在」、「那週」)放 `_data/i18n.yml`,換語言時重畫抽屜標籤與週疊標籤。
- 主題切換時重讀 token、重畫貼圖。新 token:`--sticky`、`--rule`(格線)、`--redline`(索引卡紅線),晝夜兩套。

## 效能目標

- 幾百張卡時,捲動、撥卡、換分組都跟得上螢幕更新率;靜止時不重畫。

## 分階段

每個 PR 都能建置、能在 `/shares-3d/` 打開試。

**PR 1:共用底座**
1. 抽出 `assets/scene3d/`,書架改 import。書架行為不變。

**PR 2:場景與逛**
2. 路由 `/shares-3d/`(noindex、不進導覽列)、資料 JSON、保底清單、桌子 + 週疊 + 目錄櫃的形體,捲動帶鏡頭,晝夜。
3. 卡片貼圖池(版面、印章、色標、便利貼)、抽屜標籤、分組切換。

**PR 3:互動**

**PR 4:收尾與上線**
