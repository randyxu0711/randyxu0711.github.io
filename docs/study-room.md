# 書房:房間配置、光源與材質

狀態:2026-10-23 平面圖定案,尚未實作。平面圖:https://claude.ai/artifact/LkxLyW1vCDLCS3jULeUgUs
試作(拋棄式,本機分支 `spike-materials`,不 merge):剪報桌與目錄櫃的材質、窗光投影、固定檯燈。

## 為什麼

剪報桌、書櫃、地球儀各自做得很細,但三個場景浮在同一片底色上,光是平均灑下來的,沒有交代人在房間哪裡、現在是什麼時候。
逐個場景調光行不通:沒有一個合理的房間,光的方向就沒有依據(使用者:「你要先有一個這樣合理的畫面在腦海才做得出合理的效果」)。
所以先定房間,再從房間推每個畫面看到什麼、光從哪來。

讓人感覺到位置的是空間線索:牆就在櫃子後面、桌子有邊、窗格影子跟物體的比例對。

## 目標 / 不做 / 不能變成

- **目標**:三個場景是同一個房間的三個位置;白天、夜間、桌機、手機都照同一張圖成立;材質誠實(木頭是木頭、紙永遠是紙、黃銅是金屬)。
- **不做(之後再說)**:個人擺設(印章、海報、書擋…)、吊燈、換頁時鏡頭在房間裡轉身、效能檢查(排在這之後)。
- **不能變成**:畫出燈具或窗戶本身;光跟著游標走;元件裡寫死色碼(一律走 token);首次繪製變慢或閃一下;iPhone 捲動或操作變卡;
  lo-fi「療癒書房」素材感、擺設太滿。

### 場景座標怎麼對到房間

每個場景的鏡頭都朝自己的 −z 看,所以「房間方位 → 場景軸」各不相同:

| 場景 | −z(前方) | +x(右) | 窗(西) | 夜間燈 |
|---|---|---|---|---|
| 剪報桌(`assets/shares3d/`,mm) | 北 | 東 | −x,略 +z | 檯燈:−x、靠牆(−z) |
| 書櫃(`assets/books3d/scene.js`,mm) | 東 | 南 | +z(身後),略 −x | 落地燈:+x |
| 地球儀(`assets/books3d/globe.js`,公尺) | 南 | 西 | +x,略 +z | 落地燈:−x |

## 光源規則

- **白天只有窗光**。一扇西窗,方向固定(午後,仰角約 30°)。所有亮面、影子、窗格投影都從它推出;原本「從正上方偏前打」的主光改成這個方向,環境光當天空散射。吊燈不開。
- **夜間只有兩盞燈**:檯燈(只照剪報桌)、落地燈(照書櫃與地球儀)。窗外暗,窗不進光。燈照不到的地方沉暗但不是死黑。
- **燈與窗都不畫**,只畫打出來的光。
- **光是固定的**:檯燈不再跟著游標或拿起的東西移動(書架的檯燈也是)。開場「開燈」(夜間閃兩下、白天暈開)保留,只是燈的位置固定。
- 窗格投影照真實尺寸算(每格約 300),影子邊緣離窗越遠越糊;物體(目錄櫃、書櫃)會擋光。

## 材質

- **材質 token 跟 UI token 分開**(`tokens.css`,晝夜各一套):`--wall`、`--oak`、`--oak-face`、`--paper-card`、`--paper-ink`、`--paper-ink-3`,沿用 `--brass`、`--wood`。
  UI 的 `--face` / `--card` 只給介面板(工具列、HTML 卡片框)。新色要照 `docs/redesign/SLAB.md` 的配色規則並附來源。
- **共用 shader 片段**在 `assets/scene3d/glsl.js`:木紋(遠處依 `fwidth` 淡掉,避免條紋)、紙纖維、窗光投影(含一個方盒遮擋物)。不下載貼圖。
- **紙永遠是紙**:剪報、目錄櫃的名牌、拿起的 HTML 卡,晝夜都用 `--paper-card` + 深色字。夜間在燈下是暖白,不是皮革棕。
- 目錄櫃:橡木;名牌 = 紙卡嵌黃銅框;拉手黃銅、有一點反光。tag 色條與「停留 / 按下側面變訊號色」照舊。
- 書桌:淺色木板拼接(板寬約 170)、有厚度與前緣;桌外是低 740 的地板(暗、無細節)。
- 牆:素面、極輕的灰泥雜訊;跟桌面、目錄櫃的接縫有接觸陰影。
- 書櫃:落地櫃體(側板、背板比層板暗)。地球儀:矮櫃換成同一套木頭。

## 分場景要改的

1. **剪報桌**(第一個做,試作已驗證大部分):有範圍的書桌、跟著 `cab.z` 走的北牆(`arrange()` 依桌上排數算出 `cab.z`,不能用 `CAB.Z`)、地板、接觸陰影、
   窗光投影、固定檯燈、材質 token、HTML 卡改紙色、來源章字色改 `--paper-ink`。
2. **地球儀**:白天主光改從右後方;夜間把正上方聚光燈換成左邊的落地燈,南牆光暈保留;桌子換成矮櫃 + 共用木頭。
3. **書櫃**:浮空層板改成落地櫃體;白天光從背後;夜間落地燈從右邊、固定,取代跟游標的檯燈。

每個場景完成都要:晝夜 × 桌機 / 手機(360、390、430)截圖自查,再交給使用者實測。

## 書櫃保留抽象排法(2026-10-23 決定)

270 本照真實尺寸是一面約 4 公尺、6 層的書櫃,排序、分組、索引軌會塞不下。所以**保留現在的捲動 + 層板左右滑**,只補櫃體與打光:
層板滑到底時看得到側板、層板後面有較暗的背板、每層上下是櫃體橫板。真實感來自空間線索(牆、光的方向、材質),不是書櫃的容量;
使用者:「不一定要完全真實否則既有功能就變奇幻了」。
