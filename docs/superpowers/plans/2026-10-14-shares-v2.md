# 分享頁 v2:不捲動的層級導覽、剪報卡、木頭桌櫃 Implementation Plan

> 使用者指示(2026-10-14):照示意稿 https://claude.ai/artifact/Gcof5XfGRN6k9qLvutjRbe 的方向改正式版,
> 「之前的抽屜比較好看」→ 抽屜沿用現在 WebGL 版的拉開與撥卡(往前倒),不用示意稿那種卡片升起。
> 只在本機分支 `shares-webgl` commit,不 push;code review 最後一次;做完交給使用者測,上線前先問。

**起因**:朋友回饋「捲動太長、桌上的卡字太多」。

**Goal**:首頁不再是長捲動。一進來是剪報桌,最新那張立起來對著你;`↑` 抬頭看目錄櫃(鏡頭轉向,不是捲動);
點抽屜拉開撥卡;`Esc` / `↓` / 瀏覽器上一頁退回上一層。卡片改成以 og:image 為主的剪報。桌面、櫃身、抽屜面同一種木頭。

## 決策

- **拿掉週疊**:時間軸交給桌上(最近 6 則)與櫃子的「依月份」分組。
- **剪報卡**:卡片 127×104mm(上方 og:image 1.91:1,下方標題兩行 + 來源章、日期、issue 編號)。
  圖片經 `https://wsrv.nl/?url=<og:image>&w=640&h=336&fit=cover&output=webp`(實測每張 5–25KB、帶 `access-control-allow-origin: *`,
  首次轉檔 0.8–1.4 秒,偶爾 5 秒)。**場景不等圖片**:先畫紙色塊與大字來源名,圖到了再淡入;轉不到就一直是紙色塊。
  拿起的 HTML 卡用同一個網址(瀏覽器快取裡已經有,換手時圖一致)。
- **多個 tag**:卡片上緣一排索引標籤,一個 tag 一片(最多 3 片),寫 tag 名稱,顏色同抽屜。
- **抽屜顏色提示**:依 tag / 來源分組時,抽屜面上緣一條色條、名牌左邊一條色邊(色相同卡片標籤);依月份不上色。
- **材質**:先做了木紋,使用者測過後改回原版顏色(桌面 = 頁面底色,櫃子與抽屜同書架的暖中性色),材質之後再談。
- **頁面不捲動**:footer 固定在提示列下面(使用者回報:捲動讓 footer 疊在場景上亂跑)。
- **層級與鏡頭**:`desk`(俯角約 50°,對準立起來那張)→ `cab`(俯角約 8°,整個櫃子放進畫面)→ `drawer`(沿用 `focusDrawer`)。
  層級切換 = 鏡頭 pos / look 一起內插,所以看起來是抬頭 / 低頭。
- **歷史紀錄**:進下一層 `pushState`;`Esc` / `↓` 有自己推的紀錄就 `history.back()`,否則直接換並 `replaceState`;`popstate` 換層。
  依 tag 的抽屜網址是 `#tag-<名稱>`(保留深連結)。
- **頁面高度**:舞台一個畫面高,底下照常是 footer;滑鼠滾輪照常捲頁面,不拿來換層。觸控:左右滑換一張 / 撥卡,上下滑照常捲頁面,
  換層用提示列的按鈕。

## 介面變更

- `layout.js`:`CARD` 改 127×104、`IMG_H`;`DESK = { N: 6, COLS: 3, … }`;刪 `pickDesk` 的週疊、`PILES`、`pilePose`、`pileBase`、
  `pileLabelPose`、`spreadPoses`、`focusPile`、`weekStart`、`makeCamera` / `cameraAt`;新增 `recent(items)`、`liftPose(slot, seed, a)`、
  `deskCam(pose, aspect, a)`、`cabCam(aspect, a)`、`thumb(url)`;`arrange(nDesk, nDrawers, narrow)`。
- `scene.js`:木紋 shader(桌板、櫃身、抽屜面、內盒);卡片 shader 取圖片格(`uImages`、每張 `iImg` 淡入);
  標籤每張最多 3 片、有字(`uLabels` 的 tag 格);抽屜面色條(`iColor`);`setDesk(bounds)`;刪週疊標籤。
- `textures.js`:卡片遮罩改剪報版面;第二張拼貼貼圖放圖片(同格號,載入完才畫);`createLabels` 的週疊換成 tag 名稱格。
- `held.js` / `held.css`:正面改剪報版面(圖、標題、來源章、日期、編號、上緣多片標籤、便利貼),背面不變。
- `main.js`:層級狀態機(取代捲動進度)、歷史紀錄、鍵盤 / 觸控、提示列按鈕。
- `hint.js`:新提示;`_data/i18n.yml`:刪週疊與捲動的字,加抬頭 / 低頭 / 按鈕字。
- `_layouts/shares.html`、`shares3d.css`:舞台一個畫面高、提示列加換層按鈕。
