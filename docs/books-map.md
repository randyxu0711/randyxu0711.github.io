# 書單作者地圖(地球儀)規格

狀態:2026-10-21 設計定案於原型 v15(本機 `.notes/books-map-prototype-v15.html`,不進 repo),分支 `books-map`。
書櫃旁邊站著一顆地球儀,看書單裡的作者來自哪裡;點一個國家就回到書架看那一國的書。

## 為什麼

- 書單 269 本、37 國,分布很集中(美 63、英 33、日 23、法 20、義 18、捷克 16;24 國只有 1–4 本)。
  「讀過哪些地方、哪裡還沒去」是書架本身看不出來的。
- 現成的閱讀 App(StoryGraph、Goodreads)都沒做好;社群多半手畫地圖,規則不一致(出生地?故事背景?)。
  我們自己定規則(見〈資料〉),精確數字放在旁邊的卡片(been 那類 App 的模式)。

## 參考與製圖原則

- 面量圖(choropleth)會有面積偏差:俄羅斯 4 本面積最大、捷克 16 本幾乎看不見。
  → 球只負責「哪裡讀過、大概多少」,**精確排名交給目錄卡**,小國用固定大小的點。
- 「沒讀過」是獨立的色塊,不是最淺的一級;色階標範圍(1 | 2–4 | 5–9 | 10–19 | 20+),不只標下限。
- 3D 地球儀一次只看得到半球(預設視角美國 63 本在背面)→ 目錄卡列出全部國家,點一列就把球轉過去。

## 資料

### 規則

作者依**所屬的文學圈**(寫作語言、在哪裡出版)放,不依血統或出生地。有爭議的照 Britannica 的描述;
Ishiguro 算英國(使用者的決定)。Goodreads 的拼字錯誤只在我們這邊修正。

### `_data/authors.yml`(已有,141 位)

以 `books.json` 的 `author` 字串為鍵:

| 欄位 | 說明 |
|---|---|
| `qid` | Wikidata ID |
| `literature` | 所屬文學圈的國家(英文名,對 `_data/geo.yml` 的鍵) |
| `origin` | 出生地 / 根源,跟 `literature` 不同時才寫 |
| `basis` | 判定依據(有爭議時寫出處) |
| `counts_as` | 同一人的另一個寫法 / 這本書算那位作者的 |
| `name` | 拼字修正後的名字 |

`continent` 與 `subregion` **從作者移到國家**(`geo.yml`),實作時從 `authors.yml` 拿掉,避免同一國的作者分到不同區。

### `_data/geo.yml`(新增)

一份檔案管洲、次區域、國家,地球儀與書架共用:

```yaml
continents:            # 地球儀拉遠時的洲名
  europe:   { zh: 歐洲,   en: Europe }
  americas: { zh: 美洲,   en: Americas }
  ...
subregions:            # UN M49 次區域 = 書架地區排序的一組
  northern-europe: { zh: 北歐, en: Northern Europe, continent: europe }
  ...
countries:
  United Kingdom: { zh: 英國, subregion: northern-europe, at: [-2, 53], qid: Q145 }
  United States:  { zh: 美國, subregion: northern-america, at: [-90, 39], topo: United States of America, qid: Q30 }
  ...
```

- `at`:[經度, 緯度],國名標籤、小國的點、飛近時的中心(原型的 `ANCHOR`)。
- `topo`:world-atlas 裡的名稱跟我們不同時才寫(United States of America、Czechia、Côte d'Ivoire)。
- `qid`:給 issue 加書時比對 Wikidata 的國籍(P27)。
- 分區照 **UN M49**(有統一出處,不用自己上 tag)。以現在的書:北美 72、北歐 47(英國在這裡,M49 的分法)、
  西歐 30、東亞 29、東歐 29(俄羅斯算歐洲)、南歐 22、拉美與加勒比 18、西亞 12、撒哈拉以南非洲 7、東南亞 2、澳紐 1。

### 國界

- world-atlas `countries-110m.json`(Natural Earth,公有領域;world-atlas 是 ISC)自架在 `assets/vendor/world-atlas/`,不用 CDN。
  110m 已有台灣、牙買加。
- TopoJSON 自己解(`geo.js` 約 30 行:arcs 是差分編碼,累加後乘 `transform` 的 scale 加 translate;負的 arc 編號 = 反向),
  不另外自架 `topojson-client`。
- 不用 d3:等距長方投影是線性的(`x = (lon + 180) / 360 × W`),自己畫;國界已在 180° 經線切開。
- 點到哪一國:另外畫一張**編號貼圖**(每國填自己的編號色,不反鋸齒),射線打到球的 uv 讀那一格的像素。不用 `geoContains`。

### 輸出到頁面

`_layouts/books.html` 的書 JSON 每本加 `g`(國家英文名,經 `counts_as` 解析;沒有就 `null`)、`go`(origin)。
另外輸出一份 `<script type="application/json" id="b3d-geo">`:只有書單裡出現的國家(zh / en、at、topo、subregion、continent)
與用到的洲、次區域名稱。`g` 是 `null` 的書不上地圖,也不算進卡片的本數(地區排序放在最後一組「未標國家」)。

## 書架:新增「地區」排序

| 排序 | 分組 | 組內順序 |
|---|---|---|
| 地區 | M49 次區域,一組一條層板。組的順序:洲依本數多到少(歐洲、美洲、亞洲、非洲、大洋洲),洲裡的次區域依本數多到少 | 國家依本數多到少(同國的書連在一起),同國依 `books.json` 的順序 |

- 工具列多一個排序鍵「地區」(`books3d.sort_region`),窄螢幕照舊收在「星等 ▾」選單裡。
- 層標題:「北歐 47 本」;比畫面寬的層照舊顯示「第幾本到第幾本 / 共幾本」。
- 索引軌的段落 = 次區域,長度與本數成比例(`sections` 照舊)。
- 純函式在 `layout.js` 的 `SORTS`,測試加在 `tools/books3d/`。

## 動線

三個狀態:**逛書架**、**看地球儀**、**拿起一本**。

1. **地球儀鍵**:工具列最右邊、分隔線之後,圖示鍵(地球儀),`aria-pressed`。開燈後才出現。
   - 按下:鏡頭轉向站在書櫃右邊的地球儀(停在目前捲動的高度),頁面鎖住捲動(`overflow: hidden`、canvas `touch-action: none`)。
     地球儀一開始讓歐洲朝前。
   - 再按或 Esc 一路退到底:鏡頭轉回書架,回到原本的捲動位置。點球外面不會回書架(只收掉浮起)。
   - 地球儀開著時按排法 / 排序鍵:先轉回書架再照常換。
2. **轉與縮放**:自由、連續、有慣性;**沒有洲模式、不吸附**。
   - 拖曳超過 6px 才算轉(以免吃掉點擊),只水平方向有慣性(每格乘 0.88)。緯度有上下限,拉得越近能轉越高。
   - 滾輪 / 觸控板 / 雙指捏合縮放;最近時一個國家約佔畫面一半,最遠時整顆球加底座都在畫面裡。
   - 縮放不朝游標(保留原型的做法,之後再說)。
   - 鍵盤:方向鍵轉、`+` / `-` 縮放。
3. **停留**:游標停在國家上,那一國像板子一樣**浮起來**(見〈畫面〉),沒有標籤的國家出現小提示「英國 33 本」。
4. **點國家**:
   - 國家在畫面上**小於 80px**(且還沒拉到最近):**飛近**,轉到它的 `at`,縮放到它約 240px。
   - **夠大**:**去書架**:轉回書架、換成地區排序(本來不是的話,照常洗牌)、捲到那一組、
     層板滑到那一國的第一本,那一國的書依序往外滑一下標出來,層標題暫時顯示「英國 33 本」,下一次互動就收掉。
     那一國的書比畫面寬時,對齊開頭。
   - 觸控兩段:第一下浮起 + 提示,第二下點同一國才去書架;小國第一下就飛近。
   - 點海、點沒讀過的國家:收掉浮起。
5. **Esc 一層一層退**:浮起的國家 → 拉近的鏡頭(回到最遠)→ 關地球儀 → (書架上)放回拿起的書。
6. 地球儀的狀態(轉到哪、縮放)不存 localStorage,每次打開都從歐洲朝前開始。

## 畫面

### 地球儀

- 球、黃銅子午環(1.25π 的弧,斜 20° 左右)、木柱、胡桃木底座、桌板,站在書櫃右邊;後面有一面牆(夜間的暖光打在上面)。
  比例照原型(球半徑約等於桌面視寬的 1/7)。
- **貼圖**:4096 × 2048 的 canvas 等距長方投影:海、15° 經緯線、所有陸地、讀過的國家依色階、國界線。
  夜間另一張 2048 × 1024 的發光貼圖(見〈打光〉)。只在主題切換、換語言不用重畫。
- **色階 5 級**:1 / 2–4 / 5–9 / 10–19 / 20+(`STEPS = [1, 2, 5, 10, 20]`)。沒讀過的國家是陸地色,與最淺一級明顯分開。
- **小國的點**:球面面積小於 0.001 sr(約 4 萬 km²)的國家(牙買加、以色列、台灣;原型的 0.00012 一國都沒抓到),在 `at` 畫一個固定大小的點(4096 寬上半徑 13px),顏色同色階。
  面積用經緯度環近似算球面面積(純函式,有測試)。
- **浮起**:一塊連續的板:頂面是半徑 `1 + h` 的球殼,只留那一國(遮罩貼圖 + alphaTest),
  側壁是沿國界從 1 擠到 `1 + h` 的一圈面;底下一層模糊的落影。
  原型用 10 層殼疊出來,拉到最近會看到階梯,正式版改用側壁。`h` 隨縮放變小(拉近時不用抬那麼高),
  浮起與落下用 `1 − e^(−14·dt)` 緩動。頂面描 `--edge` 邊(赤褐「游標停留」的時刻)。
- **標籤**(畫面上的 HTML 按鈕,每格算位置):
  - 國名「英國 33」:國家朝向鏡頭(面法線 · 視線 > 0.3)就顯示,**不看縮放程度**,每洲表現一致。
  - 依本數排優先,重疊的(外框加 3 × 2px 間距)後面的不顯示;離開畫面的不顯示。
  - 洲名:只在拉遠時(縮放 < 0.35)、而且比國名更朝前(> 0.6,遠離球的邊緣)才顯示,優先於國名。
    滑過洲名,整洲讀過的國家一起浮起;點洲名把那一洲轉到正面並拉近到整洲剛好放得下(不是另一個模式,之後照常自由轉、縮放)。
  - 標籤也能點,規則同點國家。字型:國名宋體(內容的名字),本數等寬。
- **游標**:可以飛近時顯示放大鏡游標,可以去書架時是手指。

### 目錄卡「閱讀版圖 / Reading map」

一張索引卡(`--card` 底、上緣反光與淡淡的外框,不歪斜),HTML,不在 3D 裡:

- 標題列:「閱讀版圖」+「37 國 / 37 countries」,下面一條 `--edge` 細線。
- 色階:「尚未涉足 / Unexplored」一格 + 5 格,下面標範圍。
- **完整的國家排名,一直展開**(沒有「顯示更多」),在卡片裡捲動:色塊、國名、本數;本數多到少,同本數依國名。
  - 列停留 = 那一國浮起;點一列 = 國家朝前且夠大就去書架,否則把球轉過去並飛近。
  - 原生捲軸藏起來,改畫一條卡片裡的 2px 捲動指示,上下緣淡出遮罩(捲到頂 / 底時不淡)。
  - 最多 16 列高(或畫面高 − 17rem)。
- 頁尾:「共 269 本 / 269 books」(上地圖的書)。
- **桌面**:卡片固定在左上,地球儀開著時才出現。
- **手機(≤ 640px)**:工具列多一個只有圖示的卡片鍵(3 個色塊 + 線 + ▾,同「星等 ▾」的樣式),只在地球儀開著時出現。
  按下在工具列上方展開全寬的卡片(最多 10 列或 42vh),直接蓋在地球儀上,地球儀不動;點外面或 Esc 收起(點外面只收卡片,不同時點到球),焦點回到卡片鍵。
  不做底部抽屜的「露出一截」。

### 打光與顏色

- **地球儀用 three.js 的物理材質與燈光**(`MeshStandardMaterial`、聚光燈、半球光):要黃銅的金屬感、胡桃木的光澤、真的聚光燈。
  書架與剪報桌照舊是自己寫的 shader(霧面、顏色跟 CSS token 一致、開場特效)。看地球儀時鏡頭已經轉過去,兩套打光不會同框比較。
- **color management**:兩個 WebGL 頁面都關著(`ColorManagement.enabled = false`、輸出不轉換),好讓 3D 的顏色跟 CSS 完全一致。
  地球儀也照這樣(使用者 2026-10-21 決定先不換算),所以燈光強度跟 v15 不同,要在關著的狀態下重新調;目前的值是第一輪,等實際看過再調。
- **白天**:半球光、主光從鏡頭左上方來(第一輪:2.2 / 2,牆面自發光 0.3),桌上有球的影子(PCF soft)。
- **夜間**:燈光要來自房間裡真的有的燈:
  - 前方略上的頂燈(聚光燈,暖白),**不投影**(投影會把桌子塗黑)。
  - 半球光補光 1.3;牆上一團暖光(球後方的點光源)。
  - 書架的檯燈在地球儀開著時關掉。
- **夜間明度層次**:牆 < 桌 < 球。海 < 沒讀過的陸地 < 讀過的國家;國界是淺色線。
  讀過的國家顏色來自**發光貼圖**,反照率壓暗,所以不會過曝成白色、各級還分得出來。
- 夜間材質:霧面灰棕的桌、亮面胡桃木底座、金屬黃銅。卡片、工具列、按鍵共用一個中性的 `--card` + 淡淡的外框。
- **顏色都進 `assets/css/tokens.css`**(晝夜兩套):`--map-1`～`--map-5`(色階)、`--map-none`、`--globe-sea`、`--globe-land`、
  `--globe-line`、`--globe-grid`、`--brass`、`--wood`、`--card`、`--card-rim`;JS 照書架的做法讀 token。v15 的值:

## 載入

- 地球儀不影響書架的首次載入與開場:開燈之後,閒置時(`requestIdleCallback`)才抓 world-atlas 與地球儀的模組、畫貼圖。
  開燈前按不到地球儀鍵;載完前按下,鏡頭照樣轉過去,球淡入。
- 地球儀不參與開場的暗房 / 素描效果(開場時它不在畫面裡)。
- 靜止時不重畫(照舊用 `invalidate()`);慣性、緩動、浮起在動的時候才排下一格。

## 無障礙

- canvas 照舊 `aria-hidden`。目錄卡的排名就是給鍵盤與螢幕閱讀器的清單:每列一個按鈕(`aria-label`「英國,33 本」),
  Enter 同點擊;Tab 到一列 = 那一國浮起並把球轉過去。卡片是 `aside`,有標籤。
- 地球儀鍵 `aria-pressed`、手機卡片鍵 `aria-expanded` + `aria-controls`。
- `prefers-reduced-motion`:鏡頭、轉動、浮起直接到位,**也沒有慣性**(原型沒關慣性,正式版關)。
- 沒有 JS / WebGL 時沒有地球儀;純 HTML 書單照舊。

## 技術

- 程式:`assets/books3d/globe.js`(地球儀的模型、貼圖、燈光、互動,動態 `import()`)、`assets/books3d/geo.js`(純函式)。
  `main.js` 只管地球儀鍵、狀態切換與「去書架」。版面的 `modules:` 加上 `geo.js`(`globe.js` 不 preload)。
- `geo.js` 的純函式(`tools/books3d/geo.test.mjs` 測):色階分級、經緯度 ↔ 球面向量、近似球面面積、
  縮放 ↔ 距離曲線(`d = R + (far − R)·((near − R)/(far − R))^z`)、點擊判定(飛近 / 去書架)、標籤的優先與重疊剔除、國家排名。
- InstancedMesh 的 boundingSphere 會從 scale 0 的矩陣算出來並快取:自己設好或 `frustumCulled = false`(原型踩過)。
- three.js 的物理燈:半球光 1 只給約 1/3 的反照率,暗的反照率加上弱補光會整片黑。
- 介面文字放 `_data/i18n.yml`:`books3d.sort_region`、`books3d.globe`(地球儀鍵)、`books3d.map_title`(閱讀版圖)、
  `books3d.map_none`(尚未涉足)、`books3d.map_countries`(`{n} 國`)、`books3d.map_total`(`共 {n} 本`)、`books3d.map_key`(卡片鍵)、
  `books3d.unplaced`(未標國家)。國名、洲名、次區域名在 `geo.yml`。

## 新書的國家(最後做)

### 用 issue 加書(`book.yml` → `add_book.py`,規格 `docs/books-issue.md`)

- 表單加一個選填欄位「作者國家」(英文國名,如 `United Kingdom`)。
- 作者已在 `authors.yml`:不動作。
- 不在的話依序:
  1. 有填「作者國家」→ 必須是 `geo.yml` 的國家,寫進 `authors.yml`(`basis: "issue #n"`)。
  2. 沒填 → 用作者名查 Wikidata(`wbsearchentities` → P27),**剛好一個國籍且在 `geo.yml`** 才寫入(附 `qid`、`basis: "Wikidata P27"`)。
  3. 還是不知道(查不到、多重國籍、國家不在 `geo.yml`)→ **書照樣發布**,留言說明、加 `needs-fix`;編輯 issue 填上國家會重跑。
     國家不在 `geo.yml` 時,留言說要先在 `geo.yml` 加這一國(中文名、次區域、`at`)。
